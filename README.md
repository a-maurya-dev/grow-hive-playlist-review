# Grow Hive playlist review

A read-only snapshot of the Ocean Friends Grow Hive induction playlists for each role, with the brief each course was built from and how many customer staff in that role watched each video. Click any video to play it in the page.

Live page: https://a-maurya-dev.github.io/grow-hive-playlist-review/

Editing, team feedback (good fit / not a fit) and creating new roles happen on the team's review page in claude.ai; this copy is regenerated from it when the playlists change.
